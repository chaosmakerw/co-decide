# 静读

打开 `index.html` 直接开始当天这一组。先回忆单词，再点“看看词义”；点“还想再练”会把它放到本轮末尾，点“记住了”才完成这个词。全部完成会自动打卡，刷新会恢复当前词、是否已经揭示词义和本轮进度。同日温习不会重复增加打卡天数。

每日固定 6 词，优先到期词，然后是未学词；不足时补入熟词温习。内置 36 个明确标记为示例词库的词条，可在词库搜索和加入最多 500 个自添词。自添只需英文与中文词义，例句可选；词库可单独温习某个词。熟悉词的下一次出现按 1、3、7、14、30 天递增，难词明天再见；这是简单的本地安排，没有学习效果或算法验证承诺。

学习足迹展示真实完成日历、累计与连续天数；提供 JSON 备份下载和恢复合并。恢复按词、日期和更新时间合并，缺少的旧记录不会被清空。存储键是 `co-decide-vocab-focus-v1`，与其他成品分开。保存失败会明确显示临时进度，提供重试与下载；异常旧记录不会自动覆盖，可下载原始内容后从备份恢复，恢复时旧原文也保存在备份数据内。

数据只属于当前浏览器的本地存储。换浏览器、移动文件后出现不同存储空间，或清理浏览数据前应下载备份。没有云同步、发音网络服务、账户、通知或真实模型。英文音标和例句为内置学习内容，自添词由使用者自行核对。

主界面延续选择的小样：冰蓝画布、阅读纸、大字英文和原创线稿；词库、今日词单、日历与备份收进右侧面板。手机按阅读顺序重排；支持键盘与减少动态效果。

核验入口：`#reveal` 揭示；`#again` 回练；`#known` 记住；`#current-word` 当前单词；`.seal` 完成印记；`#library-open` 词库；`#records-open` 足迹；`#today-overview` 今日词单；`#drawer-close` 关闭；`#add-toggle` 与 `#add-form` 添加词；`#export` / `#restore` 备份。主状态为 localStorage JSON 的 `sessions[本地日期]`；`remaining` 真正清空后才设置 `completedAt`。

本轮在本机 Edge 直接 file:// 实测主流程、回练、刷新、自添长词、HTML 文本转义、备份合并、异常记录与保存失败；截图覆盖 1440×1000 与 390×844。另通过可控日期验证次日优先复习、保留旧日打卡和跨午夜时不把旧页面的自评误记给新词。正常答案展开观察到 opacity 中间值约 0.03，最后为 1；减少动态模式也完成同样流程。证据位于 `evidence/checks.json`、`date-checks.json` 与 PNG，脚本是 `verify-focus.cjs`。本轮没有真机、长期学习效果或真实账号验证。所有本轮启动的浏览器均已关闭。
