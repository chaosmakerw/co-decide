# 背单词与打卡：选择前的三条路线

本轮只做可判断的代表小样，不做完整软件。共同输入是 harbor、gather、steady 三个词；共同结果是实际完成这组词后得到当天打卡状态。界面使用中文，内容和图形内置，直接 file:// 打开，无账户和外部模型。

## A 静读
- 体验与内容：打开即进入今天的第一个词。先回忆、再揭示词义与例句、最后自评；完成整组自动打卡。优先保护专注，代价是不能同时扫视全部词。
- 骨架：今日学习 → 单词 1 → 单词 2 → 单词 3 → 今日已打卡；“还想再练”的词回到本轮尾部。
- 画面与素材：冰蓝整屏衬一张纵向阅读纸，左边窄栏放日期和本周格点，中央以大号深蓝 Georgia 英文形成阅读重心。内置原创港湾线稿随词变化，不使用外部位图。
- 制作与动作：独立 HTML/CSS/JS，揭示答案以纸面展开反馈，自评后整段词内容短促切换，最后圆形日期印记落下。手机收起左栏，词与操作保留同一阅读顺序。

## B 今日词页
- 体验与内容：三词并排在同一张日课表里，任选顺序展开、核对和自评。学习完成后主动盖章；得到可扫视的全局与仪式感，代价是同屏信息较多、需要自己推进。
- 骨架：今日词页〔三行可展开〕 → 完成每行自评 → 右侧打卡区解锁 → 盖章留存。
- 画面与素材：近白纸面、紫黑墨色、荧光黄页签，三条宽行以词、词义抽屉、自评区组织；右侧窄票根放日期和待盖印框。印章为原创 CSS 字章，活页孔与竖向装订线服务“日课纸”构图。
- 制作与动作：独立 HTML/CSS/JS，词义按行展开，已学行留下状态；最后盖章按钮将大印落到票根上。窄屏改成连续词页，票根在词条后。

## C 词屿
- 体验与内容：从一张岛屿地图任选词语地点，进入底部学习舱，学习后回到地图，三点点亮后前往灯塔打卡。空间位置和行走反馈帮助记住进展，代价是多了一次地点选择。
- 骨架：今日地图 → 任选地点 → 回忆/揭示/自评 → 回地图 → 三地点完成 → 灯塔打卡。
- 画面与素材：浅松石海面、珊瑚粉等距岛块、深青文字；原创 SVG 等距岛屿和连线是主要信息容器，词按钮直接嵌入地点，灯塔是今天的终点。学习舱沿海面底边展开，避免地图变成装饰背景。
- 制作与动作：独立 HTML/CSS/JS 和内联 SVG，点亮地点改变节点、路线和完成数，学习舱短程上移；灯塔完成后发出静态光束与日期标记。手机保留地图整体，学习舱转成流式区。
