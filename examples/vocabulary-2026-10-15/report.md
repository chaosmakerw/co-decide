## 插件改了什么

- 新增按需读取的“构思与制作”：制作前明确使用目标、内容主次、骨架、具体画面与素材、动作反馈和窄屏做法；先把它们落实为代表小样，再选择、扩展完整产品。
- 把实际截图、连续操作与功能检查分开。动画播放、无报错、功能齐全不能单独证明画面完成度。
- 保留选择前文件，选择转成成品条件。明确获准的测试可以代选；普通“自动测试”不等于允许替用户决定。
- 已同步源码及现有本地安装，不改变版本元数据、安装状态或 Codex 配置。主入口相比本轮开始增加 301 UTF-8 字节，制作参考按需加载；字节数不是模型 token 账单。

修改位于仓库 `skills/co-decide/SKILL.md`、新增 `references/interface-craft/design-production.md` 和打包白名单。源码、示例与以下公开证据随本次上传提交。

## 三份成品的实际区别

| | 静读 · 插件路线 A | 词屿 · 插件路线 C | 拾词 · 独立对照 |
|---|---|---|---|
| 主入口 | 打开就是当前词 | 从地图任选地点 | 仪表盘进入学习 |
| 视觉组织 | 冰蓝阅读纸、大字、原创线稿 | 原创等距岛屿、地图航线、学习舱 | 米白绿色、侧栏、卡片与统计 |
| 学习 | 每日六词；回忆、揭示、两档自评 | 每日九词、每岛三词；自由次序、三档自评 | 默认每日十词，可调目标；四档自评 |
| 打卡 | 整组完成后自动记录 | 三岛完成后到灯塔主动打卡 | 达到目标后手动打卡 |
| 词库 | 36 示例词；支持自添 | 72 示例词，按地点分类 | 72 词；支持自添与批量添加 |
| 记录 | 日历、日期复习、备份合并 | 航行记录、日期复习、备份合并 | 周/月记录、日期复习、备份合并 |

静读的收益是进入快、注意力集中；固定六词和较少自评档位也是明确限制。词屿让空间位置和学习进度产生可见联系，代价是地点选择、返回地图和终点打卡带来额外操作。拾词在目标设置、词库管理和常规学习记录上更全面，熟悉的仪表盘也容易理解；首页信息量和入口步骤更多。

本轮能展示：在完整产品完成前作出的方向选择，确实贯穿了成品入口、视觉媒介、学习推进与打卡行为。它不能单独证明哪个版本适合所有人，或证明插件在相同 token 下胜出。

## 选择发生在什么时候

先制作 A 静读、B 今日词页、C 词屿的小样。根执行者实际查看三张 1440×1000 画面后，于 `selection.json` 记录选择 A/C，保留六个选择时源文件及 SHA-256，再分工制作两个成品。代选依据是它们在操作路径、视觉媒介和打卡方式上的差异最大。

这是用户授权的执行者代选，不是真实用户偏好。候选收尾中有少量措辞与路径描线修正，选择时副本始终保留原件，未用成品倒推方案。

拾词由不继承本轮对话历史的独立执行者制作，只收到原始命题、本地交付和隔离边界；未读取 Co-Decide、任何可选 Skill、旧作品或另外两份成品。它是本轮不加载 Skill 的独立对照，不代表所有配置下的原版 Codex 表现。

## 本轮实测

环境：Windows，Playwright 驱动本机 Edge 无头浏览器，真实 `file://` 页面，独立临时浏览器上下文；不访问模型、数据库或用户日常浏览器数据。不是实体手机验收。

- **统一渲染**：三个成品 × 1440/768/390 像素，9/9 通过；无整页横向溢出、未捕获脚本异常或外部网络请求。实际截图在 `qa/`，根执行者查看了三份成品的桌面、手机构图。
- **比较入口**：6/6 通过，三个成品和保留小样的链接、桌面/手机截图切换、窄屏与脚本异常检查均完成，见 `qa/gallery.json`。
- **拾词**：独立执行者 35/35 实测通过，含学习、回练、打卡、跨日、词库、备份往返及存储异常。见 `baseline/checks.json`。
- **静读**：实际完成六词及难词回练、自动打卡与重载，自添长词、备份合并、异常存储保护；补充跨日与午夜旧操作核验通过。见 `focus/evidence/checks.json`、`date-checks.json` 和实现说明。
- **词屿**：实际走完任意地点起步、重来不计完成、揭示态重载、九词三岛、灯塔打卡与恢复；损坏存储不覆盖原件、写入失败持续警告。宽窄学习态已查看，修正手机岛块拉伸。见 `island/implementation.md`、`island/evidence/`。未作长时间跨日验收。
- **插件包**：自带打包及引用完整性检查 113/113 通过。官方 `quick_validate.py` 因本机缺少 PyYAML 未能启动，没有安装或改环境；不计作通过。

统一渲染：Tests run 9，Passed 9，Failures 0，Errors 0，Skipped 0，BUILD SUCCESS（本轮实测）。

十二个配置/元数据文件的 SHA-256 保持不变；原先的未提交修改保留。三个产品分别使用独立存储键，学习记录从零开始；关闭了本轮浏览器，没有常驻服务。跨浏览器、真实手机、长期学习效果与完整 token 成本仍未验证。

本轮未收集完整模型调用账单，也未控制三份词库规模及所有附加功能，因此不推断 token 节省或普遍质量优势。

## 公开副本与复现

成品 HTML/CSS/JS 与本机验收版本逐字节相同。此目录公开三成品、选择时小样、原创截图与验证结果；排除本机配置、原始备份、浏览器资料和第三方参考图片。小样蓝图中的参考截图说明指本机研究记录，公开副本仅保留官方来源链接。

`selection.json` 保存选择时刻与小样 SHA-256；`protocol.json` 对应本提交的根目录 Skill。`publication.json` 区分成品原件与为发布改写的入口、说明、测试脚本，未改产品设计。报告中的学习效果、真机与 token 成本边界仍适用。

运行成品不需要安装依赖。可选重跑测试需 Node.js、Playwright 及可用 Chromium；从有 Playwright 的环境执行 `node qa/render.cjs`、`node qa/gallery.cjs`、`node baseline/verify.cjs`、`node focus/verify-focus.cjs`。默认采用 Playwright 浏览器，也可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定已有浏览器可执行文件。脚本中的输出仅为生成的测试数据，不应替换个人学习备份。
