## 浏览器测试的实际范围

脱敏报告见 [dorm-browser-0.5.0.json](evidence/dorm-browser-0.5.0.json)，演示代码见 [examples/dorm-habits](../examples/dorm-habits/)。历史桌面及手机宽度截图分别见 [desktop.png](../examples/dorm-habits/artifacts/desktop.png) 和 [mobile.png](../examples/dorm-habits/artifacts/mobile.png)。

12 个场景覆盖初次加载、新增及名称边界、打卡与撤销、刷新保存、身份切换和共同统计、手机宽度、隔离会话不共享、本周日期边界、名称作为文字显示、零习惯、损坏存储和写入失败。日期、空集合、损坏存储和写入失败使用明确的合成夹具；主操作流程通过真实控件执行。

历史测试使用 Playwright Core、机器已有的 Edge 和 Node.js assert，经本地静态 HTTP 服务运行；服务器和浏览器在结束后关闭。查看截图后修正手机周表布局，再对更新后的代码运行同一组场景，最终为 12/12。窄视口测试不等于实体手机或 Safari 验证。

四名室友由单浏览器的身份菜单模拟。没有独立认证、业务 API、数据库、服务端权限、跨设备同步或部署；隔离浏览器会话不共享记录是演示边界，不是多人共享功能。应用测试也没有调用真实外部模型。

## 尚未证明

- 真人连续选择、暂停和恢复是否长期可靠，以及选择是否稳定改变最终产物。
- 实际整段等待 90 分钟，以及原生提问卡片的显示时长。
- 0.5.0 的稳定隐式触发、跨宿主及跨模型兼容性。
- 最终成品优于传统多轮返工，或节省了多少 token。

90 分钟是 Skill 的超时后等待规则；模型演练和静态检查不能证明宿主会强制执行它。
