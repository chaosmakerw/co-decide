# Co-Decide

用户决定成果的使用方式与偏好，agent 负责研究、设计、实现和质量。优先共同决定产品体验与业务行为，预算主要留给成品。

## 找到值得选择的方向

先读目标、材料、有效决定和授权，查明各路线共同遵守的业务规则、角色权限与状态约束。沿使用过程识别未定的体验与业务假设，再围绕有价值的取舍收敛；用户无需点名沟通点。整体方向未定时，先探索、展示、接收选择，再完善成品；候选阶段做方向判断，成品阶段兑现选择。

共同选择须同时满足：现有信息或委托不能决定；不同答案改变主要使用路径、整体体验或重要业务后果；各路线有合理收益与代价。整体审美与氛围本身可构成重要选择，代码复杂度不是标准。事实、正确性和安全要求由 agent 查证落实；已有偏好直接沿用。

方向未定且材料中的范例不足时，用小范围检索参考同类产品与跨领域真实范例，查看实际页面、截图或流程。只保留有用链接、可迁移的视觉或机制、适用条件与代价；足以拓展候选就停止。借鉴对照原目标，不照搬参考产品的功能清单。网络不可用时说明限制，基于材料设计，不编造检索。

新建或重塑界面时，先读 [构思与制作](references/interface-craft/design-production.md) 和内置 [Frontend Design](references/frontend-design/guide.md)，同任务已读则复用；机械修改和后端任务不加载。制作前留下简短的“做什么、怎样做”：使用目标与内容主次、产品骨架、画面构思及素材、主要动作如何反馈。把构思落实为接近成品的代表页面和连续操作后再供选择，不用风格名称替代画面；明确方向后才扩展成品。构思由 agent 完成，题材假设随同一道主问题确认，不另开技术访谈或规划审批。

实现界面时按当前需要读取：[布局与主题](references/interface-craft/layout-theme.md) 将使用方式落实到层次、响应式和各路线的主题；[交互动画](references/interface-craft/interaction-motion.md) 处理状态迁移、时序与打断；确需多元素或滚动编排时再读 [复杂动画](references/interface-craft/advanced-motion.md)。候选中实现影响方向判断的布局、主题和主要转场，选定后用 [细节收尾](references/interface-craft/polish.md) 完成相关状态与一致性。复用已读指导和有效证据，细节自主落实，参考不另开审查或确认轮次。

先从产品骨架展开：谁进入、从哪里开始、围绕什么信息主体、如何导航、怎样跨页面和角色完成主任务。各路线的核心组织方式连续影响入口、信息层次或操作顺序，按实际规模覆盖关联页面，不能只改首页。骨架成立后，从题材场景、媒介或文化视觉语言推导风格；各有鲜明重点，其余内容克制地支撑它。功能与视觉可分别选择再组合，核对信息优先级、必要步骤和业务结果仍连贯，已有规格保持不变。

## 让差异可以判断

用相同真实输入比较收益与代价。界面提供可预览的完整结构及一条主要操作的小样，让整体观感与使用方式可见；业务展示同一动作后各方看到的状态、下一步，以及有依据的关键边界。需要外部依据时查有用来源并附链接，区分资料、假设与演示。

按任务要求与发散档位展示整体路线。先拓展候选再筛选，考虑符合目标却挑战默认模板的路线；推荐附依据，其余同样认真。差异不足先重设计弱路线，数量不代替质量。共用资料、已定部分、底层机制和基础组件；各路线独立组织导航、页面关系与工作区，共用布局不能提前锁死骨架。

每条路线完成同一核心任务的可判断闭环，功能差异说明先做什么、得到什么、代价是什么。辅助功能须有助主任务；过薄补足必要步骤，过重收起或删除低价值步骤。比较功能价值与操作负担，丰富度不是质量分，极简也不能省掉必要能力。

先以简短导航图说明组织差异，再用真实内容呈现代表页面和连续操作。在相同视口比较两件事：入口与任务怎样改变，构图与视觉语言怎样改变。用实际截图核对构思是否落到主画面、后续状态和窄屏；若不同名字遮住后仍像同一个模板，改造弱路线。验证影响选择的能力，其他可靠性留到选定后，共用机制只验一次；可判断即提问。每次一道主问题，用成品后果表达选项，支持混合、自由反馈和“这项你决定”。正文保留推荐、全部选项及入口，原生卡片作辅助；可用时调用 `request_user_input_async`，每次一个问题。

## 将选择落实到成品

明确反馈转成一句话或至多三条可观察条件，保留其他有效决定，直接落实。用户拒绝候选但给出可行方向时照方向改造；只有真实冲突或仍不明确的重要取舍才再问。委派传递目标、选择、约束及成品条件。

复用小样与已有实现，完善选定路线；用户明确要多份成品时，先确定整组方向，再分别完成，每份保持自己的整体一致性。新增功能与输出形式服务原目标或有效选择。用原场景验收承诺，再查一个有依据的不同输入；实际运行主要流程，并回看同视口画面与连续动作。功能通过和动画播放不能替代视觉质量判断。验证与风险相称，复用有效证据，普通缺陷自行修正，达到目标后收尾。

保留原小样入口、必要依赖和变化快照，落选路线不进入成品的日常流程。交付列明成品、小样和验证边界；本地链接核对真实绝对路径，身份切换注明演示范围。上下文只保留目标、有效选择、成品条件、当前问题与依据入口。

## 发散与等待

方向开放的整产品默认中、目标3条；用户可说“发散：低/中/高”，低最多2条、高4条，指定数量优先。已定方向或真实约束限制自由度时说明依据，保留有价值的选择。扩大路线差异而非题数，不凑数。可只调整当前一题，之后恢复任务档位；调档不算选择，不重置等待截止时间。

提问即暂停整个任务及子 agent，收到实际明确选择、可落实方向或本题委托才继续。`accepted` 等工具回执只是送出成功；空答、默认选中、超时和卡片消失均不是答案。首次超时或空答后读时钟，再等90分钟，同题只设一次截止；可中断等待每次至多60秒。到期仍无答保留原题及全部选项并暂停。宿主中断或无等待工具时用聊天保留待答题，不声称完整计时或能延长原生卡片显示。

用户明确委托代选或自主完成（包括明确授权模拟选择的自动评测）时，在该范围内选定方向并继续；普通自动测试不构成代选授权。保留选择时间、依据和小样，标明委托选择或模拟反馈，不当成真实用户偏好。

选择与小样不扩大编辑、发布、删除、付费授权。本 Skill 不修改 Codex 配置、模型参数或安装状态。
