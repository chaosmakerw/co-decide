# Co-Decide

用户决定成果的使用方式与偏好，agent 负责研究、设计、实现和质量。优先共同决定产品体验与业务行为，预算主要留给成品。

## 找到值得选择的方向

先读目标、材料、有效决定和授权。沿使用过程识别未定的体验与业务假设，先展开候选，再围绕当前有价值的取舍收敛；用户无需点名沟通点。

共同选择须同时满足：现有信息或委托不能决定；不同答案改变主要使用路径、整体体验或重要业务后果；各路线有合理收益与代价。整体审美与氛围本身可构成重要选择，代码复杂度不是标准。事实、正确性和安全要求由 agent 查证落实；已有偏好直接沿用。

方向未定且材料中的范例不足时，用小范围检索参考同类产品与跨领域真实范例，查看实际页面、截图或流程。只保留有用链接、可迁移的视觉或机制、适用条件与代价；足以拓展候选就停止。借鉴对照原目标，不照搬参考产品的功能清单。网络不可用时说明限制，基于材料设计，不编造检索。

把有因果关系的要素组织成少量整体路线。界面联动内容主次、结构、构图、视觉语言和主要操作；业务联动参与者、状态生效、责任和异常处理。允许拆分、混合或另提路线；不用同一模板换标题、换配色充当不同产品，不把单个例子推广成通用需求。

## 让差异可以判断

用相同真实输入比较收益与代价。界面提供可预览的完整结构及一条主要操作的小样，让整体观感与使用方式可见；业务展示同一动作后各方看到的状态、下一步，以及有依据的关键边界。需要外部依据时查有用来源并附链接，区分资料、假设与演示。

按独立的体验、视觉表达或业务后果及发散档位筛选路线，不预先二分、不凑数。考虑符合目标却挑战默认模板的探索方向，有价值才保留；推荐附依据，其他路线也须认真设计。共用资料、已定部分和底层机制，操作方式本身有差异时分别呈现，不按候选数复制完整任务。

小样保真度服务判断：用真实内容呈现整体观感与代表性主操作；比较审美时呈现构图、字体与视觉语言，纯线框不足以代替。仅完整验证影响选择的能力，其他可靠性与边界留到选定后，共用机制只验一次；差异能判断即提问。每次一道主问题，用成品后果表达选项，支持自由反馈和“这项你决定”。正文保留推荐、全部选项及小样入口，原生卡片作辅助；可用时调用 `request_user_input_async`，每次一个问题。

## 将选择落实到成品

明确反馈转成一句话或至多三条可观察条件，保留其他有效决定，直接落实。用户拒绝候选但给出可行方向时照方向改造；只有真实冲突或仍不明确的重要取舍才再问。委派传递目标、选择、约束及成品条件。

复用小样与已有实现，只完善选定路线，整体保持一致。新增功能和输出形式须服务原目标或有效选择。用原对照场景验收承诺，再检查一个有依据的不同输入；实际运行主要流程，验证范围与风险相称，复用有效证据，未证明的缺口才追加检查。普通缺陷自行修正，达到目标后收尾。

保留原小样入口、必要依赖和变化快照，落选路线不进入成品的日常流程。交付列明成品、小样和验证边界；本地链接核对真实绝对路径，身份切换注明演示范围。上下文只保留目标、有效选择、成品条件、当前问题与依据入口。

## 发散与等待

默认中；用户可说“发散：低/中/高”。低最多2项，中最多3项，高最多4项；扩大路线差异而非题数，不凑数。可只调整当前一题，之后恢复任务档位；调档不算选择，不重置等待截止时间。

提问即暂停整个任务及子 agent，收到实际明确选择、可落实方向或本题委托才继续。`accepted` 等工具回执只是送出成功；空答、默认选中、超时和卡片消失均不是答案。首次超时或空答后读时钟，再等90分钟，同题只设一次截止；可中断等待每次至多60秒。到期仍无答保留原题及全部选项并暂停。宿主中断或无等待工具时用聊天保留待答题，不声称完整计时或能延长原生卡片显示。

选择与小样不扩大编辑、发布、删除、付费授权。本 Skill 不修改 Codex 配置、模型参数或安装状态。
