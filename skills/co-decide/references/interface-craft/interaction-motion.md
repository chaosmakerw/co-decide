# 交互动画

制作按压、展开、切换、弹层和反馈时读取。明确动画的用途：响应操作、交代来源或衔接内容。高频操作即时响应。影响整体体验的主转场在候选小样演示，细节在选定后完成；Co-Decide 管理重要取舍。

## 从状态到实现

- 先落实静态状态、键盘与焦点。业务提交和焦点恢复由逻辑控制，取消或减少动画仍可操作；动画结束只做视觉收尾。
- 简单状态切换优先 CSS transition，需控制播放与取消用 WAAPI；沿用已有库和时序变量，单个淡入无需安装库。新 CSS 特性核对浏览器并提供静态回退。
- 菜单从触发处展开，抽屉沿进入方向退出。小幅位移、缩放或透明度交代关系；折叠高度测量内容，兼顾动态变化和溢出。
- 按距离、面积、频率调时长：按压约 100–160ms，小面板约 125–250ms；大转场可更长但不拖住操作。进出可从 ease-out、屏内移动从 ease-in-out 起步，沿用主题曲线并实测。

快速连续开关从当前值接续；WAAPI 取消前读出呈现值再重建。退出收尾识别最新操作，避免旧回调隐藏重开的面板；处理取消和零时长，不能仅等 transitionend。

`prefers-reduced-motion: reduce` 保留静态反馈，取消大位移、视差和循环。悬停运动仅在 `(hover: hover) and (pointer: fine)` 启用；触摸提供按压反馈，主要操作无需悬停。

## 观察实际运行

优先 transform/opacity，写明动画属性；合成取决于元素和环境，CSS 或 transform 均不保证 GPU 加速。高度、滤镜、大阴影和大量元素实测成本；will-change 局部按需使用并清理。

浏览器验证正常、快速往返、减少动画及触摸。中途读取 `getComputedStyle(el)` 的 opacity/transform 和 `el.getAnimations()` 的 currentTime/playState，再核对最终状态与焦点。起终点截图不能证明连续效果，模拟触摸不等于真机手感。
