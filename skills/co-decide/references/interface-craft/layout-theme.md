# 布局与主题

新建或重塑页面时，在代表小样中落实本参考；局部修改沿用当前视觉体系。每条路线围绕自己的使用方式组织内容，主题贯穿关联页面。

## 让结构表达任务

先确定阅读或操作顺序、主要信息、相关分组与密度。体验页可让构图带动情绪；操作和阅读页面让定位与反复使用稳定。用邻近关系分组，再按需要加容器；紧密与宽松间距形成节奏，重复卡片应代表确实同类的内容。

使用项目间距尺度及有语义的容器；兄弟元素优先用 `gap`。同一组件出现在不同区域时，按容器可用空间适配。窄、中、宽尺寸实际重排、折叠或换行，保持主要路径；核对视觉、DOM 和焦点顺序一致。用长标题、空内容或实际溢出情况查结构，点击目标保留足够面积，放大后仍能操作。

## 让主题成为系统

为每条路线定情绪、主色关系、对比与用色强度，尊重已有品牌。把颜色落到 CSS 语义角色：画布与层级表面、主次文字、操作与选择、焦点、分隔及业务状态；主题变化映射这些角色，跨页面一致。强色占据有意义的区域，主操作清楚；暗色主题单独设计表面层次。

项目已有色彩系统直接沿用；新色板可用 OKLCH 调整明度与彩度。检查实际前景／背景组合：普通文字以 4.5:1 为基准，符合大字定义的文本以 3:1 为基准；识别必要控件与状态的图形对比以 3:1 为基准，装饰与不可用控件按适用条件处理。核对 [文字](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 与 [非文字](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) 条件，状态还用文字或形状表达。代表截图中主次和分组能辨认，窄屏主路径成立，即可进入本阶段下一步。
